# Stock Tracking App

A simple stock register / consumable tracking web app.

## Features
- **Login** with username + password (admin and team leaders)
- **Admin** can add team leaders per subsection (Management, Quality, Logistics, Production, Paint, Safety)
- **Team leader** form to log issued/received consumables (PPE / Consumables)
- Tracks each movement against a shift employee
- Excel-export of the running totals
